# 生成与维护

## 每次新建或生成

1. 查项目已有责任入口，确认已有同职责产物及本次写入位置；不要求另建目录地图和产物登记。
2. 普通规范原地改；仅在版本或批次追溯有需要时使用revision或run-id，沿用项目已有方式。
3. 保存重要结果的实际输入引用、生成过程和位置；批量中间件需要逐项定位时复用或建立批次清单。
4. 核对实际文件、输入可定位、当前项无冲突，再更新受影响的已有责任记录。
5. 失败写未完成并保留旧当前项。报告说明哪些只生成、哪些已检查、哪些已采用。
