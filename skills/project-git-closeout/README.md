# Git 收口

版本见本目录 SKILL.md 的 metadata.version；是否已发布以仓库 Release 为准。

## 用途

根据 project-day-closeout 产出的 git_readiness，把已授权、归属明确并通过必要检查的文件分批做本地 Git 提交。

## 使用条件

需要本次有效的 git_readiness，以及明确的本地提交授权。缺少 AGENTS、索引或 profile 时，可以用 README、用户当前请求和 readiness 确定最小范围；不会因此创建项目治理文件。

## 依赖

需要 project-day-closeout 先产生本次 readiness，这是一份输入结果，不是反向安装或调用依赖。独立调用而缺少该结果时只报告缺项，不反向启动收工；不使用个人源目录或安装替代。

## 示例

“本次完整收工已经生成 readiness。请按其中的具名文件分两批做本地提交，提交前检查暂存区；不要推送，也不要把其他任务的暂存项加入提交。”

## 行为边界

audit 只读，readiness_only 本身不暂存或提交。完整收工或另有明确的具名提交请求时，才可在本次有效准备结果的范围内提交。技能不默认推送，不夹带未知暂存，不执行新的删除或搬移。已经发生的删除或改名须另有授权和恢复核查才能提交；不执行 reset、clean、强制推送或历史改写。

安装和更新时取出完整的收工三目录组合，不只替换SKILL.md。通用操作步骤见保留的完整下载包根目录下 docs/安装与更新.md。
