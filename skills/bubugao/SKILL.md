# 步步高

基于原版 grill-with-docs，只增加 Road 和 Context 适用性检查。先读取本包的 [grilling 原版](references/upstream/grilling/UPSTREAM-SKILL.md) 与 [domain-modeling 原版](references/upstream/domain-modeling/UPSTREAM-SKILL.md)，以其规则进行访谈和记录；两者是随包参考，不要求宿主安装同名技能。原始组合入口保存在 [上游入口](references/upstream/grill-with-docs/UPSTREAM-SKILL.md) 供溯源，不需要重复调用外部技能工具。

保留原版的按决定依赖分轮提问、给推荐、主动查找事实、即时记录术语及有条件记录 ADR 的方式。结束讨论不自动授权实现。只有下述两项补充影响 Road 或 Context 选择时，才采用本入口的具体规则；不要引入以前的三模板、完整需求真值或其他编排流程。

宿主兼容：原版调查事实时提到的 sub-agent 是调查方式，不是额外技能依赖。宿主支持且确有独立调查价值时可委派；不可用时由当前执行者用已有工具查证。无法取得事实则明确未知，不把可自行查证的事实问题推给用户，也不编造结果。这不增加产品能力或改变两项增强的范围。

## 补充一：Road 讨论路线

开始时明确当前讨论目标和范围，从已有材料整理四项简短内容：已经明确什么、剩余关键问题、下一步最值得先讨论什么、哪些细节可后续处理。复用已明确的答案，不要求用户重述。

- Road 是讨论路线，不是功能清单、实施计划或完整 PRD。只纳入影响当前目标的关键问题，不为了填满路线增加需求，不预铺几十层问题。
- 每个实质答案后重新判断依赖和优先级；上游未决时，不把依赖它的细节当成已经可以决定的问题。原版允许同轮询问已具备前提的问题，Road 不强制改为每轮只能一题。
- 每轮提出问题或推荐前，回看Road中已确认的边界、取舍及适用Context定义。与已确认条件冲突的选项明确标为不满足条件，不能作为等价方案推荐；新事实确需改变方向时，先说明冲突并请用户重新裁决，不悄悄替换原决定。
- 会推翻当前方向、可行性或重要承诺的细节优先，其余按需要暂缓。区分用户确认延期与 Agent 建议延期；未知事项不能自动写成承诺。
- 在目标项目明确且用户允许记录时，复用本次讨论已有的路线/接续位置；没有合适位置则采用目标项目的 ROAD.md，写前展示实际链接和本次范围。如果该文件属于别的讨论，不混写，选择具名专题位置；归属不明时只确认这一点。项目规则要求别的位置时沿用。
- 已明确的结论只保留必要摘要及实际术语/ADR链接；未产生对应文档时不造链接。发生变化后原地更新，暂停时留下一步，不生成每轮副本。只读请求时路线留在回复中，不写文件。
- 用户准备结束时说明剩余关键缺口及其影响：足以进入下一步，或仍缺决定/事实/试验，或用户选择暂停。用户明确停止时停止追问，不能用暂停或问题数量声称全部完成。

## 补充二：Context 适用性检查

在应用原版的术语写入规则前，先核对项目根、当前范围和已有入口。检查根 CONTEXT-MAP.md（如有），沿实际地图定位当前领域的 CONTEXT.md；只有根 CONTEXT.md 时检查其适用范围。缺地图不主动推演多领域体系。

检查候选文件是否：属于当前项目/领域，仍然有效，主要保存术语而非大需求汇总，与用户最新确认及现有领域地图一致。文件名、修改日期、篇幅及“只有这一份”都不能单独证明有效。

向用户给出实际文件链接、依据和以下一种判断：

| 判断 | 后续动作 |
| --- | --- |
| 沿用 | 读取其定义，按原版规则继续 |
| 局部修订 | 仅对本次已确认的术语冲突做最小更新，不改无关内容 |
| 仅作历史参考 | 不写入历史材料；若需新术语文档，先明确合适落点和与旧文档的关系 |
| 归属待确认 | 暂停依赖该归属的写入，只问关键位置或范围问题；独立讨论仍可继续 |

找不到候选时如实说明；有术语结晶后再按原版规则建立必要文件，不立即生成空文档。已有 CONTEXT 内容混杂时不自动搬移、清理或重写；不能因它叫 CONTEXT 就继续追加，也不能因它不理想就宣布其失效。多个领域含义可以不同，先明确适用范围，不强行统一成一个定义。

沿用范围内的正常更新不反复询问；出现新领域、明确过时证据或定义冲突时重新检查受影响部分。展示路径并回读写入结果，不悄悄更换记录位置。

## 保持原版边界

Context 是术语文件，符合条件的重要决定写 ADR。普通需求不保证全部落盘，Road 也不承担完整需求保存。用户确需完整需求说明时，说明这是后续单独工作，不在本技能中暗加第三项能力。权限遵循用户当前要求和项目规则；本技能的文档规则不授权删除、迁移、发布或修改已安装的其他技能。
