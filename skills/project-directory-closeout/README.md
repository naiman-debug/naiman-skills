# 项目目录收口

版本见本目录 SKILL.md 的 metadata.version；是否已发布以仓库 Release 为准。

## 用途

对具名或本轮触及的目录做最小收口：核对目录入口、README、父级索引和文件生命周期，并同步真正受影响的现有责任文件。

## 使用条件

需要一个明确的目标目录或调用方给出的范围。项目有 AGENTS、索引或 profile 时先读取；缺少这些入口时，可使用目标 README 和用户当前请求确定最小范围，并说明未覆盖部分。

## 依赖

可独立调用，没有硬依赖。由 project-day-closeout 调用时复用其发现范围与基准，只返回目录结果，不反向启动收工。

## 示例

“请只检查 docs/reports：确认其中 README 是否仍指向当前报告，父级索引是否受影响；只读列出待处理文件，不移动或删除任何文件。”

## 行为边界

audit 只读；日常收口只更新受影响的既有入口；批量移动、归档或删除需要用户对具体目录和动作的明确授权。不会扫描整个项目、重写所有 README、创建新的项目规范或递归调用完整收工。

安装和更新时取出本技能完整目录，保留参考文件；用于完整收工时将收工三目录一起更新。通用操作步骤见保留的完整下载包根目录下 docs/安装与更新.md。
